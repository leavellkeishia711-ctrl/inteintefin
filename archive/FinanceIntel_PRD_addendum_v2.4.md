## 1. Обязательный Tool Use для AI Analyst

**Проблема:**
Если AI Analyst будет отвечать на вопросы о финансах без привязки к реальным данным через tool use, есть критический риск того, что продукт будет генерировать уверенно звучащие, но полностью выдуманные (галлюцинирующие) финансовые объяснения. Для финансового инструмента это недопустимо.

**Решение (Критический риск CR-1):**
Каждый ответ AI Analyst формируется **строго** через цепочку вызовов:
1. Вопрос от пользователя.
2. Модель решает, какие инструменты (tools/functions) нужно вызвать (например, `get_pnl`, `get_cash_flow`).
3. Бэкенд выполняет реальные SQL-запросы к PostgreSQL и возвращает точные цифры.
4. Модель формирует финальный текстовый ответ **только** на основе полученных точных данных.

Прямой вызов модели для финансовых консультаций без этого шага **категорически запрещён**, даже как временный "костыль" для MVP.
