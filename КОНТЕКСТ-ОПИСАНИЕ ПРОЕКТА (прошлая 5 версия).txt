## 5. Архитектура и стек
- FastAPI, Python, SQLAlchemy 2.0, PostgreSQL 16, Alembic, RLS, Redis, Celery, Next.js 16, React 19, TypeScript, Tailwind, next-intl, TanStack Query.

## 6. Финансовая модель и источники правды
- Деньги хранятся через Decimal/NUMERIC, float в финансовых расчётах запрещён.
- Финансовые таблицы используют soft delete там, где это предусмотрено схемой.

## 7. Tenant isolation и security invariants
- company_id не должен приниматься из body, query или аргументов LLM, а берётся из JWT/session context.
- PostgreSQL RLS и tenant context являются обязательными слоями изоляции.
- Сырые секреты, токены, полные данные карт и пароли не хранятся и не попадают в LLM-контекст.

## 8. AI Analyst и tool-use policy
- обязательный tool use;
- успешный tool call обязателен перед финальным ответом;
- корректный Anthropic `tool_use`/`tool_result` flow;
- продолжение цикла после успешного инструмента;
- neutral error для LLM;
- отсутствие traceback, SQL и внутренних деталей в LLM;
- whitelist payload;
- защита от IDOR через ad_account_id/campaign_run_id;
- tenant isolation.

## 9. Telegram и alerts
- Telegram: webhook secret validation; one-time link token; expiry and reuse protection; user and tenant scoping; `/link`; `/status`; Redis rate limiting; fail-closed для `/link` при Redis outage; best-effort in-memory fallback только для некритичных операций.
- Alerts: Cash Runway threshold; ROI threshold; stalled data monitoring; dedup_key; cooldown_until; Celery Beat scheduling; tenant-isolated background execution.

## 12. STAGING ACCEPTED / PRODUCTION BLOCKED
STAGING ACCEPTED.
PRODUCTION BLOCKED.

Причины Production Blocked:
1. Не выполнен обязательный Linux/Docker Compose прогон.
2. Не подтверждён запуск PostgreSQL 16, Redis 7, двух backend workers, Celery worker и Celery Beat в Linux/Docker.
3. Не выполнен целевой Linux-нагрузочный тест asyncpg/SQLAlchemy pool.
4. Локальный Windows-тест не является заменой Linux production-gate.

## 13. Остаточные риски
- Ограничения среды Windows препятствуют 100% подтверждению отсутствия Linux-specific дедлоков event loop.
