# Reference Materials

В этой папке хранятся референсные статьи, бенчмарки и исследования, связанные с экономикой медиабаинга и арбитража трафика.
Здесь также могут лежать исследования рынка, стандарты расчётов зарплат, глоссарии и т.д.

**Эти материалы используются как источник знаний (Context) при проектировании новых фич.**
