# FinanceIntel — Документация проекта

Добро пожаловать в документацию проекта FinanceIntel (SaaS-платформа финансовой разведки и управления для медиабаинговых компаний).

Здесь собраны все ключевые документы, описывающие продукт, текущую стадию разработки, архитектуру и планы на будущее. Этот файл служит главным навигационным индексом.

## 🗂 Навигация по документам (текущая папка)
- **[MVP.md](./MVP.md)** — **Текущая стадия разработки (Stage 1 — "Financial Core")**. Детальное описание суженного фокуса продукта для запуска. Содержит то, что мы делаем прямо сейчас (каркас, мультитенантность, ручной ввод транзакций, Dashboard, базовый AI), и список того, что отложено.
- **[ROADMAP.md](./ROADMAP.md)** — **Дорожная карта**. Путь от MVP до полноценной Enterprise-инфраструктуры. Подробное описание 5 стадий развития проекта с указанием целей и будущих модулей системы.
- **[DB_SCHEMA.md](./DB_SCHEMA.md)** — **Схема базы данных**. Нормализованная схема БД (PostgreSQL) для финансового MVP. Описывает структуру данных с учетом мультитенантности, правильного хранения денег (`decimal`) и базовой аналитики.
- **[OPEN_QUESTIONS.md](./OPEN_QUESTIONS.md)** — **Решения и открытые вопросы**. Живой лог для трекинга продуктовых, юридических и технических решений. Если нужно принять решение по стеку, названию или интеграциям — это фиксируется здесь.
