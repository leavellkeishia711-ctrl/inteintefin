# FinanceIntel Privacy Policy

FinanceIntel is a software project for financial and advertising data management.

For local connector validation, the application may access read-only advertising account data from Google Ads or TikTok Ads, including campaign identifiers, dates, spend, currency, clicks, impressions, conversions, and conversion values.

Credentials are used only for authorized API requests. FinanceIntel does not intentionally publish credentials, access tokens, refresh tokens, client secrets, developer tokens, or raw API responses.

The local validation process is read-only. It does not modify campaigns, budgets, advertisements, billing settings, or account configuration.

Data collected during validation is used only to verify connector compatibility and normalize advertising metrics. Credentials may be revoked by the account owner at any time.

This test application is not intended for public consumer use. For questions about this project, contact the repository owner through the project repository.
