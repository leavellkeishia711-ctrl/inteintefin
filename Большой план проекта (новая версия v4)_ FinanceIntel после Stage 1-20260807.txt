# Большой план проекта (новая версия v4) — FinanceIntel после Stage 1

## 1. Краткое описание проекта
FinanceIntel — SaaS финансового управления и аналитики для медиабаинговых команд. Продукт выступает в роли виртуального CFO поверх трекеров (Keitaro, Binom и др.), агрегируя доходы, расходы, выплаты партнерам, зарплаты и ключевые метрики в едином интерфейсе.

## 2. Ценность продукта
Автоматизация и централизация финансов для команд арбитража трафика. Вместо ручного сведения таблиц FinanceIntel предоставляет P&L, Cash Flow, расчет Margin/ROI в реальном времени, а также AI-ассистента для аналитики.

## 3. Архитектура и структура репозитория
Стек технологий:
- **Backend**: FastAPI, Python 3.11, SQLAlchemy 2.0, Alembic, Celery, PostgreSQL 16, Redis 7.
- **Frontend**: Next.js 16.2.10, React 19, Tailwind v4, next-intl, TanStack Query.
- **Инфраструктура**: Docker Compose, GitHub Actions.

Структура репозитория:
- `01-design/`: Дизайн-материалы, макеты.
- `02-product-docs/`: Источник правды по требованиям (PRD, MVP, DB_SCHEMA, ROADMAP).
- `03-database/`: Инициализационные скрипты базы данных.
- `04-backend/`: Код backend-сервера.
- `05-frontend/`: Код frontend-клиента.
- `06-admin-frontend/` (опционально): Админ-панель (пока вне скоупа).
- `08-devops/`: Конфигурации развертывания, Docker Compose, CI/CD скрипты.
- `09-reference/`: Справочные материалы и документация по технологиям.
- `archive/`: Устаревшие материалы, черновики, логи (НЕ использовать как источник правды).
- `scripts/`: Вспомогательные скрипты.
- `scratch/`: Временная директория для промежуточных файлов агентов.

## 8. Инфраструктура и деплой
- **Локальная разработка**: Windows (uvicorn/npm run dev) или `docker compose -f 08-devops/docker-compose.yml up`.
- **CI**: GitHub Actions (Ubuntu Linux).
- Деплой осуществляется через валидацию Docker Compose стека в пайплайне `Production Gate`.

## 9. Безопасность и инварианты
- Только Decimal / NUMERIC(20,4) для денег.
- `company_id` только из JWT-сессии. RLS обязателен.
- AI Analyst отвечает только через реальный tool use с базой данных (никакого мока).
- PCI: Полные карты и пароли не хранятся.
- Секреты не логируются и не попадают в контекст LLM.
- Везде TIMESTAMPTZ в UTC и soft delete (`deleted_at`).
- Уникальность при импорте: `(company_id, source, external_id)`.
